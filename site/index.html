Audit the journey you can feel.

Automated rules can tell you what might be focusable. Focus Flow Map records what actually happened under your hands.

  1. 01

    Start on purpose

    Choose the toolbar action on the page you want to inspect. The recorder announces itself and stays visible.

  2. 02

    Navigate normally

    Use Tab and Shift+Tab. The route records labels, safe selectors, viewport position, direction, and focus styling—not what you type.

  3. 03

    Hand off the evidence

    Review numbered stations and checks for jumps, off-screen targets, loops, stalls, and absent computed focus indicators. Export in one keystroke.

LOCALBY DEFAULT

Privacy is the architecture

Your audit stays on your device.

Focus Flow Map removes query strings and hashes, redacts token-like text and emails, and never records input values. Sessions live in browser storage. No page content is sent to us. License verification sends only the license token to Sociobot.

Install in under a minute

Load the unpacked extension.

  1. Download and unzip the package.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose “Load unpacked” and select the unzipped folder.
  4. Pin Focus Flow Map, open a website, and start recording.

The Chrome Web Store listing is planned; this direct package is the v1 distribution.
