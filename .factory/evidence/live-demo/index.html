How it works

Record and share one keyboard route.

The report marks steps that need a manual check. Focus Flow Map records the route you actually used.

  1. 01

    Start recording

    Choose the extension on the page you want to inspect. A visible recorder confirms that it is running.

  2. 02

    Use Tab normally

    Use Tab and Shift+Tab. The route records safe labels, positions, direction, and focus styling.

    It never records what you type.

  3. 03

    Export the report

    Review numbered steps and checks for jumps, loops, stalls, hidden targets, and missing focus indicators.

    Export the route as Markdown or JSON.

Privacy

Your focus route stays local.

Focus Flow Map removes query strings, hashes, sensitive path values, email addresses, and token-like text.

It never records input values. Sessions stay in extension storage. No focus session is sent to us.

License verification sends only the license token to Sociobot.

Install the extension

Load the unpacked extension.

  1. Download and unzip the package.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose “Load unpacked” and select the unzipped folder.
  4. Pin Focus Flow Map, open a website, and start recording.

The Chrome Web Store listing is planned; this direct package is the v1 distribution.
